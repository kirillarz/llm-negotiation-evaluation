# Техническая реализуемость запуска Decision Models

> **Статус:** черновик  
> **Дедлайн технического пилота:** 11 октября 2026  
> **Университетский сервер:** характеристики запрошены

## 1. Цель

Оценить технические и финансовые варианты запуска Decision Models для экспериментов на русскоязычных транскрипциях.

Рассматриваются четыре основных способа запуска:

- локальные компьютеры участников команды;
- университетский сервер;
- API разработчиков моделей;
- облачные GPU-платформы.

## 4. Возможные способы запуска

| Способ | Преимущества | Ограничения | Предварительный статус |
|---|---|---|---|
| Локальный запуск | Нет расходов на API или аренду, данные остаются локально | Ограниченный VRAM, возможные проблемы совместимости | Подходит для небольших/квантованных моделей |

## 7. Технические ограничения и риски

Основные риски, которые необходимо учитывать:

- недостаток VRAM;
- несовместимость модели с доступным runtime;
- необходимость квантизации;
- увеличение потребления памяти при длинных транскрипциях;
- ограничения максимальной длины контекста;
- возможные проблемы с поддержкой русского языка;
- ограничения внешних API;
- требования к конфиденциальности транскрипций;
- недоступность или недостаточная мощность университетского сервера.

## 8. Предварительная схема проведения экспериментов

### Предпочтительный вариант

**Университетский сервер**, если его характеристики подходят для выбранных моделей.

### Резервный вариант 1

**Официальный API модели**, если:

- веса закрыты;
- локальный запуск технически сложен;
- необходимо быстро выполнить пилот.

### Резервный вариант 2

**Облачная GPU**, если:

- модель имеет открытые веса;
- университетский сервер недоступен или недостаточно мощный;
- локального оборудования команды недостаточно.

### Локальный запуск

Использовать для:

- разработки экспериментального пайплайна;
- первоначальных тестов;
- небольших или квантованных моделей;
- проверки корректности входных и выходных данных.
