# Сравнительная таблица Decision-моделей

В шорт-лист отобраны 3 перспективных кандидата с открытыми весами и 1 проприетарная модель в качестве идеального бейзлайна. Для задач анализа русскоязычных транскрипций критически важны окно контекста (чтобы влезал весь текст разговора) и качество логического вывода на русском.

| Название | Разработчик | Доступ | Лицензия / Ограничения | Преимущества | Потенциальные проблемы |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Qwen 2.5 (14B / 32B Instruct)** | Alibaba Cloud | Open Weights (HuggingFace), API | Apache 2.0 (бесплатно для коммерции). Веса доступны для скачивания. | Лучший русский язык среди открытых моделей. Окно контекста до 128k токенов (идеально для длинных транскрипций). Отличные способности к reasoning и структурированию данных. | Для версии 32B потребуется сервер с минимум 24 ГБ VRAM (при квантовании). |
| **Llama 3.1 / 3.3 (8B / 70B Instruct)** | Meta | Open Weights, API | Meta Llama License (разрешено коммерческое использование до 700 млн пользователей). | Огромная экосистема инструментов (vLLM, llama.cpp). Высокая предсказуемость форматов вывода (JSON). | Менее нативный русский язык по сравнению с Qwen (иногда сбивается на английский при сложных промптах). |
| **DeepSeek-V3 / R1 (или Coder V2)** | DeepSeek | Open Weights, API | MIT License / Открытая. | Выдающиеся математические и логические (decision) способности, сопоставимые с топовыми закрытыми моделями. | Требует значительных ресурсов для локального запуска из-за архитектуры MoE (Mixture of Experts) и размера. |
| **GPT-4o-mini / o1-mini** *(Резерв)* | OpenAI | Только API | Проприетарная. Данные передаются на серверы OpenAI (не подходит для NDA-данных). | Не требует настройки железа. o1-mini имеет встроенную цепочку рассуждений (CoT). Низкая цена за 1M токенов. | Сложности с оплатой API (нужна иностранная карта). Возможные блокировки по IP. |

**Рекомендация по моделям:** 
Основным кандидатом для исследований с открытыми весами стоит выбрать **Qwen 2.5 (14B/32B)** благодаря идеальному балансу между требованиями к железу и нативной поддержкой русского языка в длинных текстах. Для быстрого API-тестирования логики промптов использовать **GPT-4o-mini**.
