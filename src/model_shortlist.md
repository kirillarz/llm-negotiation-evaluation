
## Сравнительная таблица Decision-моделей (Осень 2026)

| Название | Разработчик | Особенности | Способ доступа | Ограничения | Документация / Источник | Плюсы | Минусы / Риски |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **Clef (27B) / Clef-Flash (9B)** | Cloudflare | Возвращает вероятностное распределение ответов вместо текста. Базируется на Qwen3. Сверхбыстрая работа (Flash <40мс). | Открытые веса (Apache 2.0), Workers AI API | Не генерирует текст. Локальный запуск 27B требует GPU уровня H200. | [Hugging Face Model Card], [Cloudflare Blog] | Идеальна для предсказуемых агентных циклов и маршрутизации; прозрачность уверенности модели. | Нет официальных бенчмарков по русскому языку (хотя база Qwen3 его поддерживает). |
| **GLiDE** | Fastino Labs | "Thinking Decision Model". Включает внутреннее рассуждение перед выдачей жестко структурированного решения. Контекст 40k. | Закрытый API (Fastino API) | Строгое ограничение размера промпта (отбрасывает при >40k). Проприетарная. | [Fastino Labs API Docs] | Решает многошаговые логические задачи (выбор из 100+ инструментов, анализ контрактов). | Платный API; закрытые веса делают невозможным дообучение (RLHF) под специфику компании. |
| **Strands Decider 2B** | AWS | Сверхкомпактная модель для базового выбора действий и Guardrail-защиты. | Open-source | Низкая емкость сложного контекста из-за 2B параметров. | [AWS Open Source / GitHub] | Запуск на слабом железе локально (<150мс); нулевые затраты на облако. | Может плохо справляться с грязными или сленговыми русскими транскрипциями. |
| **Jev** | TypeSafe | System One модель. Выдает строго типизированные, откалиброванные решения. | Проприетарный API | Подвержена специфичным промпт-инъекциям (по данным ИИ-исследований октября 2026). | [TypeSafe Portal] | Гарантирует типизацию возвращаемых данных; легко интегрируется в код. | Зависимость от одного вендора (vendor lock-in). |
| **Decisions API (GPT-6 Luna)** | OpenAI | Отдельный эндпоинт, запущенный на DevDay 2026, для выбора из предопределенного списка вариантов. | OpenAI API | Полностью закрытая экосистема; тарификация за облачные вызовы. | [OpenAI API Reference] | Высший уровень базового интеллекта и мультиязычности (отличное понимание русского). | Высокая совокупная стоимость владения (TCO) на больших объемах данных. |
