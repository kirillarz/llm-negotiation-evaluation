# Метрики сравнения

## 1. Формат данных

- **LLM:** возвращает выбранного победителя переговорного поединка.
- **Decision-модель:** возвращает вероятность голоса за каждого игрока.
- **Профессиональные судьи:** для каждой коллегии сохраняются 3 отдельных голоса.

## 2. Основные метрики

### 2.1. Agreement Rate (Accuracy)

**Что измеряет:** долю случаев, в которых решение модели совпадает с решением большинства судей коллегии.

**Формула:**

`Agreement Rate = число совпадений / общее число поединков`

**Порядок расчёта:** для каждого поединка определяется победитель по большинству голосов судей и сравнивается с выбором модели.

### 2.2. Individual Judge Agreement

**Что измеряет:** среднюю долю совпадений решения модели с голосами отдельных профессиональных судей.

**Формула:**

`Individual Judge Agreement = число совпадений с отдельными голосами / общее число сравнений модель–судья`

**Порядок расчёта:** решение модели отдельно сравнивается с каждым из трёх голосов судей коллегии, после чего рассчитывается средняя доля совпадений.

### 2.3. Agreement by Collegium

**Что измеряет:** согласованность модели с каждой судейской коллегией отдельно.

**Порядок расчёта:** Agreement Rate рассчитывается отдельно для каждой коллегии.

### 2.4. Cohen's Kappa

**Что измеряет:** степень согласованности решения модели с решением большинства судей с поправкой на случайные совпадения.

**Формула:**

`κ = (p_o - p_e) / (1 - p_e)`

где:
- `p_o` — наблюдаемая доля совпадений;
- `p_e` — ожидаемая доля случайных совпадений.

**Порядок расчёта:** бинарные решения модели и большинства судей используются для построения таблицы совпадений, после чего рассчитывается κ.

### 2.5. Human–Human Agreement

**Что измеряет:** степень согласованности профессиональных судей между собой.

**Порядок расчёта:** сравниваются голоса судей внутри коллегий. Метрика используется как человеческий baseline для интерпретации согласованности моделей с судьями.

## 3. Дополнительные метрики

### 3.1. Macro-F1

**Что измеряет:** качество предсказания победителя с учётом обоих классов.

**Формула:**

`Macro-F1 = (F1_игрок1 + F1_игрок2) / 2`

**Порядок расчёта:** для каждого игрока отдельно рассчитываются precision, recall и F1, после чего F1 усредняются.

### 3.2. Repeatability / Consistency

**Что измеряет:** стабильность решения модели при повторных запусках на одинаковых данных.

**Порядок расчёта:** для каждой судейской коллегии выполняются 3 запуска модели. Сравнивается, насколько часто итоговые решения совпадают между повторными запусками.

### 3.3. Position Bias (Label Flip Rate)

**Что измеряет:** долю случаев, когда модель меняет выбор победителя после перестановки обозначений первого и второго игрока.

**Формула:**

`Label Flip Rate = число случаев изменения решения / общее число повторно проверенных поединков`

**Порядок расчёта:** один и тот же поединок повторно подаётся модели с переставленными позициями игроков, после чего сравниваются решения.

### 3.4. Brier Score

**Применяется:** к Decision-модели.

**Что измеряет:** качество вероятностного прогноза относительно решения большинства судей.

**Формула:**

`Brier Score = (1/N) * Σ(p_i - y_i)^2`

где:
- `p_i` — вероятность голоса за выбранного игрока, выданная Decision-моделью;
- `y_i` — фактический исход по решению большинства судей (`0` или `1`);
- `N` — число поединков.

**Интерпретация:** чем меньше Brier Score, тем лучше вероятностный прогноз.

### 3.5. Vote Share Error (MAE)

**Применяется:** к Decision-модели.

**Что измеряет:** среднее абсолютное отклонение вероятности Decision-модели от фактической доли голосов профессиональных судей за игрока.

**Формула:**

`MAE = (1/N) * Σ|p_i - v_i|`

где:
- `p_i` — вероятность Decision-модели;
- `v_i` — фактическая доля голосов судей за игрока;
- `N` — число поединков.

**Интерпретация:** чем меньше MAE, тем ближе вероятностные оценки Decision-модели к распределению голосов профессиональных судей.

## 4. Итоговый набор

**Основные метрики:**
- Agreement Rate (Accuracy)
- Individual Judge Agreement
- Agreement by Collegium
- Cohen's Kappa
- Human–Human Agreement

**Дополнительные метрики:**
- Macro-F1
- Repeatability / Consistency
- Position Bias (Label Flip Rate)
- Brier Score
- Vote Share Error (MAE)
