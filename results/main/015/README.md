# Результаты основного эксперимента 015

25 октября 2026 года. 25 поединков (ID 6–30), три коллегии, original/swapped, по три независимых голоса каждой модели на условие. Получены все 900 голосов: Clef — 450, Qwen 3.8 Flash — 450. Выполнена 901 техническая попытка: один временный сбой Clef устранён автоматическим повтором. Qwen работал с reasoning.effort=none; фактическое число reasoning-токенов — 0.

Тела запросов восстановлены **после запуска** штатными адаптерами из кода и входов, чьи хеши совпадают со снимком до первого вызова. Это реконструкция, а не перехват исходящего HTTP-трафика. Хеш каждого тела сверяется с независимым аудитом. Повторных запросов к моделям при подготовке архива не выполнялось. Для связи с реальными ответами используются model_alias, bout_id, collegium, variant и repeat_index.

calls.jsonl содержит реальные ответы провайдеров. Вероятности сохранены там, где их возвращал провайдер; Qwen выдавал только JSON с choice. Заголовки авторизации и ключи API в архив не включены.

Конфигурация именно этого запуска находится в evaluation_snapshot.json и metadata.json; текущие рабочие файлы репозитория могут относиться к другой конфигурации. Согласие с людьми — референсный показатель, а не объективная правильность. Разница частоты смены победителя Clef 24% против Qwen 16% статистически не подтверждена. Пояснение к совместной гипотезе H3 есть в experiment_report.md.
